## P0 优先级（核心功能）

### 1. 保持原文模式增强
**现状**: 仅即触AI提供，云章已支持但需优化

**预期收益**: 解决用户反馈中"内容被篡改"痛点

### 2. 学术模板库扩充
**现状**: 竞品学术模板偏少

**预期收益**: 占据学术场景差异化优势

### 3. 免费额度策略 ✅
**现状**: Kimi 免费+积分制已验证  
**目标**: 设计免费额度方案，降低用户门槛  
**预期收益**: 提升获客与留存  
**定案（Hermes 整合 + Codex 实现细节 + Claude 绑定建议）**: 每日 10 次计数器，表 `usage_log(user_id, generated_at, ip)`，限流走日期键滑动窗口；`FREE_DAILY_LIMIT=10` 配置项；积分制放 Phase 4

## P1 优先级（体验优化）

**执行顺序（JARVIS 已确认）**: 移动端适配 → 长文本优化 + 协作功能 MVP **并行**

### 4. 协作功能 MVP（@Codex）
**现状**: 无竞品完美实现，WPS AI 有基础协作  
**目标**: 实现基础实时协作（评论、批注）  
**预期收益**: 满足团队协作需求

**预期收益**: 满足学术研究场景  
**并行约束**: 只动 `_fill_keep_original()` 相关后端切分逻辑 + keep-original 开关周边组件

### 6. 移动端适配（@Claude）

**预期收益**: 覆盖移动办公场景
