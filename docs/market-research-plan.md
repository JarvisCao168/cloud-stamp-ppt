## 数据整理规范

### 收集格式

每条反馈记录包含：

| 字段 | 说明 | 示例 |
|------|------|------|
| `channel` | 来源平台 | 小红书/B站/抖音 |
| `content_type` | 内容类型 | 评论/弹幕/帖子 |
| `raw_text` | 原文摘录 | "讯飞智文排版太死板了" |
| `sentiment` | 情感倾向 | 负面/中性/正面 |
| `pain_point` | 痛点分类 | 排版/内容/模板/交互 |
| `feature_request` | 功能需求 | 智能排版/自定义模板 |
| `use_case` | 使用场景 | 答辩/汇报/路演 |
| `source_url` | 原文链接 | https://... |
| `collect_date` | 收集日期 | 2026-09-10 |

### 文件命名

```
D:/yzppt/docs/market-research/
├── feedback-collected.json       # 原始反馈数据
├── pain-points-frequency.csv     # 痛点频次统计
├── feature-requests-analysis.md  # 功能需求分析
├── competitor-comparison.md      # 竞品对比总结
└── screenshots/                  # 反馈截图归档
    ├── xiaohongshu/

```
