# Kimi PPT 评测报告

## 基本信息
- **官网**: https://www.kimi.com/zh/slides
- **厂商**: Moonshot AI (月之暗面)
- **模型**: K3 大模型驱动
- **价格**: 每月免费积分额度，免费策略

## 核心功能

### 输入方式
- 一句话主题生成
- 粘贴文字内容
- 上传文档（PDF/Word/PPTX/Excel/TXT/图片）

### 模板风格
提供丰富的模板分类：
- 自定义风格
- 工作汇报
- 金融投资
- 战略咨询
- 宣传推广
- 学术研究

具体模板名称（中式美学风格）：
- 青绿答辩、松绿战略、暖陶作品、松烟画报
- 天蓝导视、暖玉年报、银灰奢刊、酒红数据
- 宣纸年刊、电紫商务、粉彩推导、黑金经营
- 深蓝图谱、奶油拼贴、红黑商务、杏白私报
- 月白影像、水蓝慈报、玄蓝黑石、蜜橙备忘
- 展望年刊、缃黄杂志、海蓝研究、旅绿手册
- 苔绿转型、纸白课件、蓝线课件、湖蓝备忘
- 靛青尽调、蓝焰品牌

### 核心优势
1. **完全免费** - 每月有积分额度，无需付费即可使用完整功能
2. **长文本理解** - K3 模型支持超长上下文，可处理万字文档
3. **信息源校验** - 引用内容经过真实信息源验证
4. **模板设计质量高** - 中式美学风格，配色专业
5. **支持多种输入格式** - PDF/Word/PPTX/Excel/TXT/图片
6. **可编辑输出** - 支持下载为可编辑 PPTX 文件
7. **在线预览/放映** - 生成后可在线修改

### 劣势/不足
1. **非学术模板偏少** - 虽然有青绿答辩等学术风格，但整体偏向商务/工作汇报
2. **设计感相对弱** - 相比 Gamma，视觉冲击力稍逊
3. **模板类型有限** - 约30个模板，相比 Gamma 的丰富生态略少
4. **协作功能** - 未见明显多人协作功能
5. **AI 二次编辑** - 功能较基础，主要是模板切换

## 与云章PPT对比

| 功能 | Kimi PPT | 云章PPT |
|------|----------|---------|
| 免费策略 | ✅ 月度免费积分 | ✅ 测试期免费 |
| PPTX导出 | ✅ 可编辑 | ✅ 可编辑 + 序号样式 |
| 序号样式 | ❌ 无 | ✅ 30种样式库 |
| 长文本 | ✅ K3模型 | ⏳ 待集成 |
| 自定义模板 | ⚠️ 有限 | ✅ 支持上传 |
| 保持原文模式 | ❌ 无 | ✅ 特色功能 |
| 学术模板 | ⚠️ 较少 | ✅ 针对性设计 |
| 团队协作 | ⚠️ 未明确 | ✅ 规划中 |
| 智能推荐 | ⚠️ 基础 | ✅ AI推荐序号样式 |

**云章差异化优势**:
1. 序号样式库（30种）- Kimi 无此功能
2. 保持原文模式 - Kimi 会改写内容
3. 学术场景针对性优化
4. 私有化部署规划
