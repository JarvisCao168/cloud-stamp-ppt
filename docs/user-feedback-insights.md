## 核心发现
1. PPTX导出兼容性是硬门槛，Gamma导出效果差是最大槽点
2. 付费模式是最大痛点，Kimi/豆包免费策略受用户欢迎
3. 70%用户需二次编辑，一次生成可用率低
4. 中文支持不足，国外工具中文效果差于国内工具
5. 局部精细编辑需求强烈，现有工具迭代成本高
