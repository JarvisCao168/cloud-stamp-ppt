## 二、核心测试维度（统一评分制）

### 维度定义与权重

| 维度 | 权重 | 评分标准 (1-5分) |
|------|------|------------------|
| **D1. 内容生成质量** | 25% | 1=严重事实错误/逻辑混乱；3=基本可用需大改；5=精准提炼可直接用 |
| **D2. 模板与排版水平** | 20% | 1=模板老旧/排版混乱；3=及格线；5=专业级设计感 |
| **D3. 中文支持度** | 15% | 1=中文体验差/乱码；3=基础支持；5=中文排版专业流畅 |
| **D4. 二次编辑灵活性** | 15% | 1=只能在线改/无法导出；3=可导出基础格式；5=完整导出+自由编辑 |
| **D5. 导出兼容性** | 10% | 1=格式错乱/缺少格式；3=主流格式齐全；5=完美兼容Office/WPS |
| **D6. 生成速度** | 5% | 1=超过5分钟；3=2-3分钟；5=60秒内完成 |
| **D7. 价格门槛** | 10% | 1=免费版几乎不可用；3=有可用免费版；5=免费额度充足 |

## 三、统一测试用例

### 测试用例 TC-01: 主题生成（标准输入）
- **输入**: "2025年Q3销售团队年度业绩总结"
- **期望**: 自动生成30页左右PPT，大纲结构清晰（背景-成果-问题-规划）
- **记录**: 生成耗时、大纲合理性、初稿完成度

### 测试用例 TC-02: 文档生成
- **输入**: 上传同一份3000字技术报告（Word格式）
- **期望**: 自动提炼要点、结构化展示，不篡改原文数据
- **记录**: 原文保留率、数据准确性、关键信息覆盖度

### 测试用例 TC-03: 模板丰富度
- **方法**: 不限定主题，随机生成3份不同风格PPT
- **记录**: 可用模板数量、风格多样性、高级感程度

### 测试用例 TC-04: 导出测试
- **方法**: 用同一份PPT导出为 PPTX + PDF + PNG
- **记录**: 导出成功率、格式保持度、导出耗时

### 测试用例 TC-05: 协作功能
- **方法**: 邀请测试账号共同编辑同一份PPT
- **记录**: 实时协作体验、评论/批注功能、权限管理

## 四、自动化辅助方案

### 可脚本化的测试点
1. **API 接口测试**（Gamma/Beautiful.ai 如有公开API）
   - 批量生成测试用例，记录响应时间
   - 自动化检查导出文件格式完整性

2. **页面截图文本提取**
   - 使用 Playwright 自动截图关键步骤
   - OCR 提取生成内容用于文本质量对比

3. **性能数据采集**
   - 记录各步骤耗时（大纲→初稿→编辑→导出）
   - 生成性能对比图表

### 手动测试必做项
- 内容质量主观评分（需人工判断）
- 设计美学评估（视觉冲击力）
- 中文排版细节（字体/间距/对齐）
